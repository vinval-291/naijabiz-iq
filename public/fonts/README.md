# Fonts

Self-hosted so the app works without Google Fonts (offline demo, no build-time downloads).
Declared with `@font-face` in `src/app/globals.css`.

| Family | Files | Source | Licence |
|---|---|---|---|
| Inter (variable) | `inter-latin*-wght-normal.woff2` | `@fontsource-variable/inter` | SIL Open Font License 1.1 |
| Outfit (variable) | `outfit-latin*-wght-normal.woff2` | `@fontsource-variable/outfit` | SIL Open Font License 1.1 |
| IBM Plex Mono 400/500 | `ibm-plex-mono-latin*-normal.woff2` | `@fontsource/ibm-plex-mono` | SIL Open Font License 1.1 |

Each family has a `latin` and a `latin-ext` file; `latin-ext` contains the naira sign (₦, U+20A6).
